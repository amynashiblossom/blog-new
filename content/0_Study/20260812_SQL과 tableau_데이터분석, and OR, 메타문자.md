[테이블 특성]
각 테이블은 튜플 (행)들의 집합

하나의 칼럼에는 하나의 데이터형태값만 가진다
ex 하나의 칼럼에 이름 : 문자열
열의 순서가 큰 의미를 갖진 않는다.

튜플은 유일해야 함.
ex. 동명이인이라 하더라도 empno로 구분지어서 하는데
"키값"할당 : 인간에게는 주민등록번호 부여해서 구분하듯

각 행은 기본키(primary 키를 갖는다) =>empno가 pk!!!! #primarykey

각 애트리뷰트(열)은 오직 하나의 원자값을 갖는다.
하나의 셀에 여러 값을 넣는 것은 허용되지 않음
한 셀에 하나만(다른 스타일의 nosql?에는 여러값 포함하기도 하는데 기본적으로 sql에선 한 셀에 하나만)

각 애트리뷰트(열) 이름은 테이블 내에서 고유해야 함
같은 테이블 안에서는 중복된 열 이름을 사용할 수 없음

튜플(행)순서가 바뀌더라도 동일한 행으로 이해(ex 영업 행이 1에 있든지 순서가 아래로가든지)

-테이블의 key란 
보통 기본키(#primarykey ):각 튜플(행)을 고유하게 식별하는 하나 이상의 속성
-중복될 수 없고 null 값 가질 수 없음

-외래키(foreign key)
-다른 테이블의 기본키를 참조하는 속성
-테이블 간의 관계를 정의함.
ex 학교에 선생님이 1반 담임선생님, 2반의 담임선생님, 3반의 담임선생님
이럴때 1반의 담임선생님은 1반의 다른 키과 관계될 듯.
