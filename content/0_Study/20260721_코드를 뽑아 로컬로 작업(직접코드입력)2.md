4-1 실습 : 명찰에 이름 명단을 하나하나 반영시키는 것을 자동화 시키기

*프롬프트*
아래 조건에 따라 엑셀의 명단을 PPT 템플릿에 자동으로 입력하는 VBA 코드를 작성해줘.

**1. 파일 및 데이터 설정**

- **파일 선택**: 실행 시 엑셀 명단 파일과 PPT 템플릿 파일(.pptx)을 각각 선택하는 창을 띄울 것.
- **엑셀 데이터**: 활성화된 시트의 B열(소속)과 **C열(성명)** 데이터를 2행부터 마지막 행까지 사용함.
- **호환성**: 별도의 참조 설정 없이도 실행되도록 **Late Binding** 방식으로 작성할 것.

**2. PPT 슬라이드 생성 및 매칭 로직**

- **구조**: PPT 템플릿의 첫 번째 슬라이드는 명찰 4개가 배치된 형태이며, 각 명찰에는 "소속"과 "성명"이라는 텍스트가 입력되어 있음.
- **복제 방식**: 원본(1번 슬라이드)은 데이터 수정 없이 그대로 유지하고, **매번 1번 슬라이드를 복제하여 맨 뒤에 붙인 뒤, 그 복제된 슬라이드에 데이터를 입력**할 것.
- **텍스트 치환**: 개체 이름(Shape Name)이 아닌, 도형 안의 **텍스트가 "소속" 또는 "성명"과 정확히 일치하는지 확인**하여 엑셀 데이터로 교체할 것.
- **슬라이드당 인원**: 한 슬라이드에 4명씩 채우고, 인원이 4의 배수가 아니면 남은 칸은 템플릿 상태(소속/성명)를 유지함.

**3. 마무리 작업**

- 모든 데이터 입력이 끝나면, 맨 앞에 남아있는 **데이터가 입력되지 않은 원본(1번 슬라이드)을 자동으로 삭제**할 것.
- 완료 후 파워포인트 화면을 띄워둔 상태로 메시지 박스를 출력할 것.

스크립트 : ## 역할

안녕. 너는 구글 Apps Script 웹 앱 구축 전문가야.

## 요청사항

1. 구글시트에 저장된 FAQ 데이터를 불러와 질문과 답변을 웹페이지에 표시해줘.
2. 사용자가 질문을 등록할 수 있는 입력 폼을 만들어줘.
- 작성자(선택)
- 질문 제목
- 질문 내용
3. 사용자가 등록한 질문은 Q&A 목록에 게시판처럼 쌓이게 보여줘.
4. Q&A 데이터에서 답변이 있는 질문은 답변을 함께 표시하고 답변이 없는 질문은 “답변 대기중”으로 표시해줘.
5. 교육생이 구글시트에 답변을 입력하면, 해당 내용이 웹페이지에 자동으로 반영되게 해줘.
6. Apps Script 코드는 Code.gs와 index.html 구조로 구성해서 만들어줘.
