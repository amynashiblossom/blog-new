# [PRD] AI 냉장고 레시피 추천 서비스  
  
## 1. 서비스 개요  
- **개요**: 보유한 냉장고 재료를 입력하면 AI가 가능한 요리를 추천하고, 조리법과 부족한 재료를 안내하는 서비스  
- **목적**: 음식 고민 시간 단축 및 남은 재료 활용을 통한 음식물 쓰레기 감소  
  
## 2. 주요 기능 목록 (MVP)  
1. **재료 입력 (FEAT-01)**  
   - 재료 직접 입력 (최소 1개 ~ 최대 20개, 중복 입력 불가)  
   - 예외 처리: 미입력 시 경고 문구 출력, 특수문자 제한  
2. **AI 레시피 추천 (FEAT-02)**  
   - 입력된 재료 기반으로 최대 5개의 레시피 추천  
   - 카드 형태 출력: 음식명, 예상 시간, 난이도, 활용 재료, 부족한 재료  
3. **레시피 상세 보기 (FEAT-03)**  
   - 선택한 레시피의 단계별 번호(Step) 조리 순서, 상세 재료 안내  
4. **즐겨찾기 (FEAT-04)**  
   - 마음에 드는 레시피 저장/삭제 기능 (중복 저장 불가)  
5. **부족한 재료 안내 (FEAT-05)**  
   - 보유 재료 외에 추가로 필요한 양념/재료를 별도로 강조 표시  
  
## 3. 정보 구조 (IA)  
- **홈**: 재료 입력 폼, 입력된 재료 태그 목록, AI 추천 시작 버튼  
- **추천 결과**: 레시피 카드 리스트 (난이도, 시간, 부족 재료 요약)  
- **레시피 상세**: 음식 정보, 단계별 조리 순서, 즐겨찾기 버튼  
- **즐겨찾기**: 저장한 레시피 목록 및 삭제 기능
