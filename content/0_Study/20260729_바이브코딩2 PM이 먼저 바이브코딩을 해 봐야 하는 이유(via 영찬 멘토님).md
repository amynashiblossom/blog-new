*영찬 멘토님은 NGO연계 컴퓨팅 교육(말라위)6개월 진행하시기도 함*
vibe coding - 자연어로 ai에게 지시하여 컴퓨터 코드를 작성하게 하는 것.
안드레이 컴파시가 2025.2에 처음 트윗으로 언급한 표현

코드가 존재한다는 사실조차 잊어버린다 => 코드를 읽지 않는다 / 결과만 봅니다.

기존 코딩 vs 바이브 코딩
바이브 코딩은 : **==무엇을 원하는 지에 대한 명확함==**
디버깅도 "고쳐달라고 ai에게 요청"하면 됨.

지금이 바이브코딩을 활용하기에 적합한 상황인 이유가
**모델 성능**이 LLM가 실제로 동작하는 코드를 쓰기 시작했고,
작성, 실행, 미리보기, 배포가 한 화면 안으로 들어온 **도구통합**
비용도 **무료** 등급으로 오늘 바로 시작 가능

바이브코딩이 설명하는 기획에서
동작하는 화면을 보여주는 "보여주는 기획"으로 줄어들게 됨.
