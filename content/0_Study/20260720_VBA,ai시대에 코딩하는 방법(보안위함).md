[[엑셀 VBA 코드 만들기]]

1. 데이터 취합
![[20260720_vva,ai시대에 코딩하는 방법(보안위함)_박사동료가 논문 위한 연구를 하는 방식을 위해1.png]]
아래 기능을 수행하는 엑셀 VBA코드를 만들어줘

- 특정 폴더에 있는 여러개의 엑셀 파일을 하나로 취합하는 코드

-특정 폴더 : 윈도우 대화상자로 맥파인더로 사용자가 직접 지정

-1행은 제목행이므로 1번만 가져옴

-> 오류가 났을 경우, 수정해줌

2. 분리 대상 데이터
파일을 열어서 
c열만 분리하기 
->아래의 기능을 수행하는 앱스스크립트 코드를 각각 만들어줘

-현재 활성화된 시트의 c열 값을 기준으로 동일한 값을 가진 행들을 각각 별도의 시트로 분리하는 코드를 만들어줘

시트 이름은 해당 c열의 값으로 설정해줘.

3. 범용코드 만들기
vba 코드 만드는 프롬프트

##요청사항
아래 작업을 수행하는 VBA 코드를 만들어줘.

##세부사항
1. 코드를 실행하면, 작업 대상 엑셀 파일을 선택할 수 있게 윈도우 대화상자를 만들어줘.
2. 내가 선택한 엑셀 파일 Sheet1 데이터의 열을 입력할 수 있게 대화상자를 만들어줘.
- 예를 들어 A, B, C 등을 입력
3. 내가 선택한 열을 기준으로 동일한 값을 가진 행들을 각각 별도의 시트로 분리해줘.
4. 작업을 모두 완료하고 엑셀 파일은 닫지 말고 열어줘.
