# 🔒 Security & Privacy Specification

## 1. 개인정보 처리 및 데이터 보호 (Data Privacy)
* **최소한의 개인정보 수집**:
  * 구직자의 식별에 필요한 기본 정보(이메일, 이름)만 필수 수집하며, 민감한 개인 정보(주민등록번호, 주소 등)는 수집하지 않음.
* **웹 포트폴리오 URL 보안 (Public/Private Access Control)**:
  * **공개 범위 설정**: `전체 공개`, `비밀번호 보호 공개`, `비공개(본인만 보기)` 3가지 모드 제공.
  * **비밀번호 보호 기능**: 퍼스널 URL 전달 시 전용 접근 비밀번호를 설정할 수 있도록 하여 채용 담당자 등 지정 대상만 열람 가능하게 조치.

## 2. 영업비밀 & 대외비 데이터 보안 (Data Masking & Security)
* **대외비 마스킹 토글 (One-Click Data Masking)**:
  * **마스킹 대상**: 프로젝트 작성 폼 내 `주요성과`, `매출 수치`, `내부 프로젝트 코드명`, `유저 지표` 등.
  * **작동 메커니즘**:
    * 작성 모드에서 데이터 원본 입력 후 `[대외비 마스킹 보안 토글] ON` 설정 시, 외부 전달용 웹 포트폴리오 페이지에서는 해당 영역이 블러(Blur) 처리되거나 `***` 형태로 치환하여 출력.
    * 예시: `매출 50억 달성` ➔ `매출 [대외비] 달성` 또는 `매출 5*억 달성`
* **법적/보안 가이드라인 알림 (In-App Compliance Warning)**:
  * 프로젝트 성과 작성 폼 하단에 "이전 직장/기관의 계약상 대외비 및 보안 위반 요소가 포함되지 않도록 주의하세요" 보안 경고 문구 및 가이드라인 제시.

## 3. 아키텍처 및 시스템 보안 (Technical Security)
* **전송 구간 및 저장소 암호화**:
  * 모든 데이터 전송 구간 HTTPS (TLS 1.3) 적용.
  * 데이터베이스 저장 시 사용자 데이터 AES-256 암호화 저장.
* **검색 엔진 노출 방지 (SEO Indexing Control)**:
  * 유저의 웹 포트폴리오 페이지에 `noindex, nofollow` 메타 태그 옵션 기본 지원.
  * 구글, 네이버 등 검색 엔진 크롤링 노출로 인한 불필요한 개인정보 및 프로젝트 정보 유출 방지.
