HYPOTHESIS TEST · [가설 2] · 종로구 혜화동 · PC방 업종(CS200019)

혜화동 PC방은 주중보다 주말에 매출이 더 높을까?

trade_area × sales 조인 쿼리를 기준_년분기_코드로 GROUP BY하여 20개 분기 각각을 개별 행으로 집계한 결과(2번가설_검증자료.csv)를 기반으로, ① 전체 기간(2021Q1~2025Q4)과 ② 2025년만(2025Q1~Q4) 두 범위로 가설을 검증합니다.

상권: 대학로(혜화역) · 종로구 혜화동 업종: CS200019 (PC방) 쿼리 그레인: 분기별 (20행)
실행한 SQL 보기 (분기별 그레인 + QoQ/이동평균 확장) 
-- 1) 기본 분기별 집계 쿼리
SELECT
    s.기준_년분기_코드, t.자치구_코드_명, t.상권_코드_명, s.서비스_업종_코드, 'PC방' AS 업종명,
    SUM(s.당월_매출_금액) AS 총_매출_금액,
    ROUND(SUM(s.주중_매출_금액)/5, 0) AS 주중_일평균_매출,
    ROUND(SUM(s.주말_매출_금액)/2, 0) AS 주말_일평균_매출,
    ROUND((SUM(s.주말_매출_금액)/2)/NULLIF(SUM(s.주중_매출_금액)/5,0), 2) AS 주말_대비_주중_매출배수
FROM trade_area t JOIN sales s ON t.상권_코드 = s.상권_코드
WHERE s.기준_년분기_코드 BETWEEN 20211 AND 20254
  AND s.서비스_업종_코드 = 'CS200019'
  AND (t.상권_코드_명 LIKE '%대학로%' OR t.상권_코드_명 LIKE '%혜화%')
GROUP BY s.기준_년분기_코드, t.자치구_코드_명, t.상권_코드_명, s.서비스_업종_코드
ORDER BY t.상권_코드_명, s.기준_년분기_코드;

-- 2) 서브쿼리로 감싸서 QoQ 증감 + 4분기 이동평균 추가
SELECT *,
    총_매출_금액 - LAG(총_매출_금액) OVER (ORDER BY 기준_년분기_코드) AS QoQ_증감액,
    ROUND(AVG(총_매출_금액) OVER (
        ORDER BY 기준_년분기_코드 ROWS BETWEEN 3 PRECEDING AND CURRENT ROW
    ), 0) AS 총매출_4분기이동평균
FROM ( /* 위 1)번 쿼리 */ ) base
ORDER BY 기준_년분기_코드;
