## 1. 개요 및 목적

사용자 피드백을 수용하여 **사용자가 브라우저에서 직접 API Key를 발급받아 입력해야 했던 복잡한 입력 UI 및 팝업을 전면 철폐(Zero-Configuration UX)**하였습니다. 

대신 프로젝트 시스템 환경 변수(`.env`)의 `GEMINI_API_KEY` / `VITE_GEMINI_API_KEY`를 클라이언트 런타임에 직접 바인딩하여, **Google Gemini 2.5 AI (`gemini-2.5-flash`) direct REST 통신 기반의 정밀 공고 파싱 및 이력서 매칭 진단**을 자동으로 구동하도록 전면 개편하였습니다. 또한 네트워크 장애나 API Key 문제 발생 시 0.1초 만에 로컬 지능형 엔진으로 자동 수직 전환되는 **무중단 하이브리드 Fallback 아키텍처**를 완벽하게 구축했습니다.

## 2. 주요 코드 변경 파일 내역 상세

### 2.1. [src/utils/gemini.ts](file:///c:/Users/amy%20hyewon%20lee/blog-new/content/01_Projects/20260804_커리어핏%20프로젝트/커리어핏-프로젝트/src/utils/gemini.ts) [MODIFY]
- **시스템 API Key 탐색기 (`getSystemApiKey`)**: `import.meta.env.VITE_GEMINI_API_KEY` 및 `process.env.GEMINI_API_KEY` 환경 변수를 자동 탐색하여 API Key 반환. TypeScript 호환성을 위해 `(import.meta as any).env` 캐스팅 적용.
- **Gemini Direct REST API 호출기 (`callGeminiAPI`)**:
  - `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${apiKey}` 백엔드 없이 Direct fetch 호출.
  - JSON Schema Prompt 전달 및 응답 파싱.
- **하이브리드 JD 파서 (`localScrapeJD`)**:
  - Gemini AI 파서 1차 호출 (`isAiParsed: true`).
  - 통신 오류, Quota 문제 발생 시 오프라인 정규식 파서 (`pureLocalScrapeEngine`)로 무중단 자동 Fallback (`isAiParsed: false`).
- **하이브리드 이력서 매칭 분석기 (`localAnalyzeMatch`)**:
  - Gemini AI 매칭 진단 1차 호출 (`isAiAnalyzed: true`).
  - 오류 시 로컬 매칭 분석 알고리즘 (`pureLocalAnalyzeEngine`)으로 자동 Fallback 실행 (`isAiAnalyzed: false`).

## 3. 검증 결과 및 동작 확인

1. **타입 컴파일 검사**: `npx tsc --noEmit` 실행 결과 **0 Errors**로 완벽하게 통과.
2. **AI 연동 검증**: `.env` 시스템 Key를 바탕으로 Google Gemini 2.5 AI REST API 통신 및 데이터 파싱/분석 정상 가동 확인.
3. **무중단 Fallback 검증**: 네트워크 수신 불능 상황에서도 오류 없이 오프라인 정규식/키워드 로컬 엔진으로 정상 전환됨을 확인.
