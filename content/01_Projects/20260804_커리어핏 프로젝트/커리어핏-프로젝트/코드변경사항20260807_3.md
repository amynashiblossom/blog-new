# [코드 변경사항] API Key 완전 제거, Pure Local 오프라인 파싱 엔진 전환 및 이력서 암호화 고도화 (v3)

**작성일자**: 2026년 08월 07일

**대상 시스템**: 커리어핏 (CareerFit) Pure SPA 서비스

## 1. 개요 및 목적
사용자 요청에 따라 외부 API Key(Gemini API 등) 통신 의존성을 100% 제거하고, 내 컴퓨터(브라우저 로컬 환경)에서 전 과정을 처리하는 **Pure Local 아키텍처**로 완벽하게 개편하였습니다. 또한 사용자가 등록/첨부한 이력서 및 서류 원문 데이터가 브라우저 LocalStorage에 안전하게 저장되도록 **로컬 데이터 암호화(Encrypted Storage)**를 구축하였습니다.
