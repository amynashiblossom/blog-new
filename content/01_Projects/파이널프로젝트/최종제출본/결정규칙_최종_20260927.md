## A. 공통

2. 정수 구간 "A~B" = A 이상 B 이하, 비율은 소수점 버림. 시간 구간(반응 속도·도착 여유)은 구간표 경계를 따르고 경계값은 높은 점수 쪽

4. ✏️ 정렬: 그룹 A 정상 → B 근무시간 겹침 → C 결격(겹침과 결격이 둘 다면 C). 점수로 그룹을 넘지 못한다. 그룹 안은 총점 내림차순 → 0순위 소계 → 1순위 소계 → 지원 시각 빠른 순 → 지원 ID 오름차순
5. ✏️ 중립값은 계산 불가일 때만, 4곳뿐: 0순위 #1 9.0 · #4 1.5 · #6 1.0 · 2순위 도착 가능성 4.0

## C. 0순위 무단결근방지

11. ✏️ #1 무결근 완료율 = 스팟 완료 ÷ (완료 + 무단결근 + 확정 후 취소) × 100, 소수점 버림. 사업주 취소·인정 취소는 분모에서 제외. 전체 기간. 분모 3건 미만이면 9.0
12. ✏️ #2 정규직 무단결근 이력: 전체 기간. 있으면 0, 없으면 6.0(정규 이력이 없어도 6.0). 있으면 이미 0번 규칙으로 그룹 C이므로, 이 점수는 그룹 C 안의 순서에만 쓰인다
